\subsubsection{Ferramentas de análise: SAST, DAST, IAST}

As ferramentas de análise identificam vulnerabilidades ao longo do ciclo de vida da aplicação. O SAST (\textit{Static Application Security Testing}) analisa código ou \textit{bytecode} sem execução e é adequado para CI/CD \cite{Alazmi2022WebScannerReview}. O DAST (\textit{Dynamic Application Security Testing}) testa a aplicação em execução, enquanto o IAST (\textit{Interactive Application Security Testing}) combina instrumentação dinâmica com evidências do código para reduzir falsos positivos \cite{Cotroneo2025IASTvsRASP}. Evidências recentes indicam que a combinação das três abordagens amplia cobertura e efetividade \cite{DeJesus2023SecurityTestingWebApps}.

\subsubsection{Defesas em \textit{runtime}: WAF, WAAP, RASP}

Defesas em \textit{runtime} atuam em produção. O WAF (\textit{Web Application Firewall}) filtra tráfego HTTP por regras e assinaturas, com limitações típicas de abordagens \textit{black-box} \cite{Doupe2010IntrusionDetectionCrawler}. O WAAP amplia a proteção para APIs, e o RASP (\textit{Runtime Application Self-Protection}) atua dentro da aplicação, usando contexto de execução para elevar a precisão e mitigar ataques \textit{zero-day} \cite{SuredaRiera2025TwentyTwoYearsXSS}.
